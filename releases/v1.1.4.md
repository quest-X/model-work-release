# OpenSight Suite v1.1.4

## 中文

### 更新简介

本版本发布 OpenSight 全系列安装包命名与平台矩阵预览，面向用户统一使用
`x64`、`ARM64` 和 `Universal`，不再在下载页面使用容易混淆的 `x86_64`。

| 组件 | 版本 | 本次变化 | 分发方式 |
| --- | --- | --- | --- |
| model-work-frontend | 2.9.1 | 未变化 | 公开 |
| model-work-backend | 1.1.0 | 未变化 | 私有 |
| model-work-node | 1.1.2 | 未变化 | 私有 |
| model-work-extension | 未建立统一版本 | 未变化 | 私有 |
| model-work-monitor | 未建立统一版本 | 未变化 | 私有 |

| 平台 | 架构 | 规划文件名 | 状态 |
| --- | --- | --- | --- |
| Windows 10/11 | x64 | `OpenSight-1.1.4-windows-x64.exe` | 规划中 |
| Windows 11 ARM | ARM64 | `OpenSight-1.1.4-windows-arm64.exe` | 规划中 |
| Linux | x64 | `OpenSight-1.1.4-linux-x64.run` | 规划中 |
| Linux | ARM64 | `OpenSight-1.1.4-linux-arm64.run` | 规划中 |
| NVIDIA Jetson Linux | ARM64 | `OpenSight-1.1.4-linux-arm64-jetson.run` | 规划中 |
| macOS Intel | x64 | `OpenSight-1.1.4-macos-x64.pkg` | 规划中 |
| macOS Apple 芯片 | ARM64 | `OpenSight-1.1.4-macos-arm64.pkg` | 规划中 |
| macOS 通用包 | Universal | `OpenSight-1.1.4-macos-universal.pkg` | 规划中 |

本预览版没有上传安装器二进制。只有完成对应系统构建、测试和公开安全审查后，
安装包状态才会变为 `available`。

### 公开边界

公开附件仅包含安装包矩阵、套件清单、签名、公钥和 SHA-256 校验表。
私有源码、程序载荷、凭证、私有下载地址、客户配置和内部部署信息均未上传。

## English

### Summary

This release publishes the OpenSight installer naming and platform matrix
preview. User-facing architecture names are standardized as `x64`, `ARM64`,
and `Universal`; the download page no longer exposes the confusing
`x86_64` label.

### Component baseline

| Component | Version | Change | Distribution |
| --- | --- | --- | --- |
| model-work-frontend | 2.9.1 | Unchanged | Public |
| model-work-backend | 1.1.0 | Unchanged | Private |
| model-work-node | 1.1.2 | Unchanged | Private |
| model-work-extension | No unified version | Unchanged | Private |
| model-work-monitor | No unified version | Unchanged | Private |

### Installer targets

| Platform | Architecture | Planned filename | Status |
| --- | --- | --- | --- |
| Windows 10/11 | x64 | `OpenSight-1.1.4-windows-x64.exe` | Planned |
| Windows 11 ARM | ARM64 | `OpenSight-1.1.4-windows-arm64.exe` | Planned |
| Linux | x64 | `OpenSight-1.1.4-linux-x64.run` | Planned |
| Linux | ARM64 | `OpenSight-1.1.4-linux-arm64.run` | Planned |
| NVIDIA Jetson Linux | ARM64 | `OpenSight-1.1.4-linux-arm64-jetson.run` | Planned |
| macOS Intel | x64 | `OpenSight-1.1.4-macos-x64.pkg` | Planned |
| macOS Apple silicon | ARM64 | `OpenSight-1.1.4-macos-arm64.pkg` | Planned |
| macOS universal | Universal | `OpenSight-1.1.4-macos-universal.pkg` | Planned |

No installer binary is attached to this preview. A target becomes `available`
only after it is built, tested on the matching operating system, and approved
for public distribution.

### Public boundary

Public assets contain only the installer matrix, suite manifest, signature,
public key, and SHA-256 checksums. No private source, payload, credential,
private download location, customer configuration, or internal deployment
detail is included.

## Acceptance boundary / 验收边界

This release confirms the public installer matrix and signed metadata only.
It does not claim installer execution, private package delivery, OTA
completion, service deployment, browser acceptance, or field acceptance.

本版本只确认公开安装包矩阵和签名元数据，不代表安装器执行、私有程序交付、
OTA 完成、服务部署、浏览器验收或现场验收。
