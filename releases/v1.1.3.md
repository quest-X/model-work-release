# OpenSight Suite v1.1.3

This release changes the public distribution model from a single Node package
to a complete `model-work-*` suite baseline.

## Component baseline

| Component | Version | Change | Distribution |
| --- | --- | --- | --- |
| model-work-frontend | 2.9.1 | Added to suite manifest | Public |
| model-work-backend | 1.1.0 | Added to suite manifest | Private |
| model-work-node | 1.1.2 | Added to suite manifest | Private |
| model-work-extension | Unversioned revision | Added to suite manifest | Private |
| model-work-monitor | Unversioned revision | Added to suite manifest | Private |

No component source release is claimed by this suite update. The manifest pins
the existing component baseline and establishes consecutive suite versioning.

## Public files

- `suite.json`
- `suite.json.sig`
- `suite.publisher.public.json`
- `SHA256SUMS`

No private source, package, artifact URL, credential, customer configuration,
or internal deployment detail is included.

## Legacy release

The public assets previously attached to `v1.1.2` were withdrawn after a
verified private backup because they did not meet the current public release
boundary. Its tag and release record remain as history.

## Acceptance boundary

This release confirms public metadata publication only. It does not claim
private package delivery, OTA completion, service deployment, browser
acceptance, or field acceptance.
