# OpenSight Suite v1.1.5

## 更新简介 Summary

本版本统一安装包矩阵的阅读顺序和双语展示格式。平台顺序调整为
Linux、macOS、Windows、NVIDIA Jetson Linux；中文始终显示在上方，
英文在下一行显示。

This release standardizes the installer matrix order and bilingual layout.
Platforms are ordered as Linux, macOS, Windows, and NVIDIA Jetson Linux.
Chinese is always shown first, with English on the next line.

## 公开边界 Public boundary

公开附件仅包含安装包矩阵、套件清单、签名、公钥和 SHA-256 校验表。
私有源码、程序载荷、凭证、私有下载地址、客户配置和内部部署信息均未上传。

Public assets contain only the installer matrix, suite manifest, signature,
public key, and SHA-256 checksums. No private source, payload, credential,
private download location, customer configuration, or internal deployment
detail is included.

## 验收边界 Acceptance boundary

本版本只确认公开安装包矩阵和签名元数据，不代表安装器执行、私有程序交付、
OTA 完成、服务部署、浏览器验收或现场验收。

This release confirms the public installer matrix and signed metadata only.
It does not claim installer execution, private package delivery, OTA
completion, service deployment, browser acceptance, or field acceptance.
