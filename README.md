# model-work-release

**中文** | [English](README_EN.md)

OpenSight 统一套件的公开版本索引与经审查制品仓库。

## 范围

各 `model-work-*` 子仓库按自身版本正常发布 Release。
本仓库只在明确指定统一发布时使用，例如 OpenSight 大版本或 OTA 套件。
私有组件只公开必要的版本元数据，不会在这里发布源码、私有安装包、
下载地址、凭证或内部配置。

## 版本

- OpenSight 套件版本从 `v0.0.1` 开始，并独立连续递增。
- 子仓库版本保持独立，不因普通子仓库发版自动生成套件版本。
- 只有收到明确的统一发布指令后，才创建套件标签和 Release。
- 当前尚未发布统一套件版本。

## 安装包

每次统一套件发布单独列出经过构建、测试和公开审查的安装包。
只有 Release 中实际上传的文件才代表可下载制品。

## 信任

- 套件清单使用 [`suite.publisher.public.json`](suite.publisher.public.json)
  中的 Ed25519 发布者公钥验证。
- 客户端必须在本地固定发布者公钥和获准的 HTTPS 来源。
- 公开制品必须绑定准确的文件大小和 SHA-256 摘要。
- GitHub 传输不能替代清单签名验证。

## 安全

完整规则见 [`SECURITY.md`](SECURITY.md)。无法确认适合公开分发时，默认不上传。

## 许可

本仓库中的版本元数据不授予私有组件的访问权。公开制品的分发条件以对应版本说明为准。
