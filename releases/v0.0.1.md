# OpenSight Installer v0.0.1

## 更新简介 Summary

本版本提供首个可下载运行的一键安装器预览版，支持 Frontend、Backend、
Node、Extension、Monitor 多选，Frontend 可选择 `main` 通用主线版或
`commercial` 现场商业部署版，并在执行前确认安装计划。

This release provides the first runnable one-click installer preview. It supports
multi-select for Frontend, Backend, Node, Extension, and Monitor. Frontend can use
the general `main` channel or the `commercial` field-deployment channel, followed
by installation-plan confirmation.
